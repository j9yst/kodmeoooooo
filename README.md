## Краткое описание программы
**Expense Chart** - это консольное приложение на Python для учета личных финансов с возможностью визуализации расходов. Программа позволяет добавлять, просматривать, фильтровать и анализировать расходы, а также строить наглядные графики распределения средств по категориям.
### Основные возможности:
- **Управление расходами**: добавление, просмотр и удаление финансовых операций- **Категоризация расходов**: 8 предустановленных категорий (Еда, Транспорт, Развлечения, Покупки, Коммунальные услуги, Здоровье, Образование, Другое)- **Типы расходов**:   - Обычные расходы  - Обязательные расходы (коммунальные платежи, кредиты и т.д.)  - Расходы на досуг (с оценкой уровня удовольствия 1-10)- **Фильтрация данных**:   - По категориям  - По временному периоду (начальная и конечная дата)- **Аналитика**:  - Подсчет суммы расходов за выбранный период  - Детализация по категориям с процентным соотношением- **Визуализация**:  - Круговая диаграмма распределения расходов по категориям  - Столбчатая диаграмма для сравнения категорий  - Линейный график тренда расходов по месяцам- **Сохранение данных**: автоматическая загрузка/сохранение в JSON файл
### Технологии:- Python 3.7+- Matplotlib - для построения графиков- Datetime - для работы с датами- JSON - для хранения данных
### Принципы ООП:- Инкапсуляция (скрытие внутренних полей через геттеры/сеттеры)- Наследование (разные типы расходов наследуются от базового класса Expense)- Полиморфизм (переопределение методов to_dict() и __str__)
