## Краткое описание программы

Task Manager — это консольное приложение, разработанное с использованием объектно-ориентированного программирования (ООП) и шаблона проектирования Model-View-Controller (MVC). Оно позволяет пользователям эффективно управлять своими задачами напрямую из командной строки. Приложение поддерживает создание, редактирование, удаление задач, а также фильтрацию по приоритету и статусу. Для обеспечения постоянства данных используется формат JSON для сохранения и загрузки списка задач. В приложении также реализованы функции отмены последних действий (undo) и управления задачами по приоритету с использованием очереди.

## Как запустить приложение

Предварительные требования:

Установленная версия Python (рекомендуется Python 3.6+).
Git (для управления версиями, опционально для запуска).

## Скачивание кода:

Клонируйте репозиторий (если код будет размещен в Git):
bash
git clone <URL_вашего_репозитория>
cd <название_папки_проекта>
ИЛИ создайте файл main.py и вставьте в него предоставленный код.

Запуск:
Откройте терминал или командную строку.
Перейдите в директорию, где находится файл main.py.
Выполните команду:
bash
python main.py
